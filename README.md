# WordReCorrectWithAI

ヘアサロン検索サービスを想定した、**入力ミス（タイポ）サジェスト TUI アプリ**です。
ユーザーの入力が1秒以上止まると、LMStudio 上のローカル LLM（既定: Gemma2 2b）で「タイポか？」を判定し、意図したであろう正しい単語をサジェストします。

```
🔍 入力> カッt_
💡 もしかして: カット   [Tab=確定]      ← 1秒後に表示
```

## ✨ 特徴

- **1秒デバウンス判定**: 入力のたびにタイマーをリセット。1秒無入力でのみ AI を呼び出し、推論中の追加入力は前回タスクをキャンセルして無駄を省きます。
- **語彙をまるごと AI に読み込ませる**: 起動時に `tmp.txt` の全単語をシステムプロンプトへ埋め込み、毎回の判定で参照させます（LMStudio のプレフィックスキャッシュで高速）。
- **起動時にモデルを選択**: LMStudio の `/v1/models` API からロード済みモデル一覧を取得し、↑↓+Enter で選択。埋め込みモデルは自動除外。
- **誤提案ガード**: カタカナ↔ひらがなを正規化した類似度判定で、無意味入力（`aaaa` など）へのデタラメ提案を防止。
- **完全一致は高速パス**: 語彙と完全一致する正しい入力は AI を呼ばず「✔ 正解」。
- **[Tab] で確定 / [Enter] で送信**: サジェストを Tab で入力欄に反映。

## 🧰 動作環境

- **Python 3.10+**
- **[LMStudio](https://lmstudio.ai/)** でローカル LLM サーバーを起動（既定: `http://localhost:1234/v1`）
- Python パッケージ（すべてインストール済みの前提）:
  - `openai`, `httpx`, `requests`, `prompt_toolkit`, `rich`
  - `difflib`（標準ライブラリ）

> 新規環境で導入する場合: `pip install openai httpx requests prompt_toolkit rich`

## 🚀 セットアップ

### 1. LMStudio でモデルをロード
LMStudio を起動し、モデル（例: `gemma-2-2b-it`）をダウンロード＆ロード → **Developer / Server** タブで **Start Server** を押します。

### 2. テスト用語彙ファイルを準備
判定のベースになる正しい単語リストを `tmp.txt` に作成します。`words.txt`（5970語のヘアサロン検索語彙）から先頭 N 語を切り出せます。

```bash
python extract_words.py 200      # 先頭200語を tmp.txt へ
```

> Gemma2 2b（コンテキスト約8k）では **数〜数百語** が無難です。語数は `tui_app.py --check` で確認できます。

## 📖 使い方

### 対話モード（メイン）
```bash
python tui_app.py
```
起動するとモデル選択ダイアログ → 入力プロンプトの順で進みます。

| 操作 | 動作 |
|---|---|
| 文字入力 → 1秒放置 | AI がタイポ判定。ミスなら下部にサジェスト表示 |
| `Tab` | サジェストを入力欄に確定 |
| `Enter` | 入力を送信（結果を1行出力して継続） |
| `Ctrl-C` / `Ctrl-D` | 終了 |

### モデルを固定したい場合（選択ダイアログを省略）
```bash
python tui_app.py --model gemma-2-2b-it
```

### 1回だけ判定（非対話・スクリプト向け）
```bash
python tui_app.py --once "カッt"
# 入力: カッt
# サジェスト: カット
```

### 起動診断（語彙数・モデル・プロンプト長の確認）
```bash
python tui_app.py --check
```

## ⚙️ 設定

### CLI オプション
| オプション | 既定値 | 説明 |
|---|---|---|
| `--words` | `tmp.txt` | 読み込む語彙ファイル |
| `--model` | *(対話選択)* | LMStudio のモデルID。省略時は起動時に一覧から選択 |
| `--base-url` | `http://localhost:1234/v1` | LMStudio の API URL |
| `--debounce` | `1.0` | 無入力判定までの秒数 |
| `--check` | — | 起動診断のみ行い終了 |
| `--once INPUT` | — | 1回だけ判定して終了（非対話） |

### 環境変数
| 変数 | 既定値 | 説明 |
|---|---|---|
| `LMSTUDIO_MODEL` | `gemma-2-2b-it` | `--model` 未指定時のフォールバック／選択ダイアログの初期カーソル |
| `LMSTUDIO_BASE_URL` | `http://localhost:1234/v1` | `--base-url` の既定値 |

## 🧠 仕組み

```
打鍵毎にタイマーリセット
        │
   1.0秒 無入力
        │
   ┌────┴────────────────────────────┐
   │ 入力 ∈ 語彙 ?                    │
   │   Yes → 「✔ 正解」(AI呼ばない)    │
   │   No  → Gemma2 2b へ推論リクエスト │
   └────┬────────────────────────────┘
        │  system: 語彙全件 + 書式指示
        │  user:   入力文字列
        │  出力:   "SUGGEST: <単語>" or "OK"
        ▼
   解析 ＋ 類似度ガード（ひらがな正規化）
        │
   ミスと判定 → ツールバーにサジェスト表示
```

- **プロンプト設計**: 小モデル（2b）でも堅牢になるよう、出力を `SUGGEST: <単語>` / `OK` の1行に制限（`stop=["\n"]`, `max_tokens=32`, `temperature=0.1`）。書式例も同梱。
- **類似度ガード**（`ai_checker.py` の `SIMILARITY_THRESHOLD=0.5`）: 提案語が入力と似ていない場合は採用しない（ハルシネーション除外）。`へあさろん`→`ヘアサロン` のような正規化で一致するケースは保持します。

## 🛠 トラブルシューティング

| 現象 | 対処 |
|---|---|
| `⚠ 警告: 指定モデル ... はロードされていません` | LMStudio で該当モデルをロードするか、`--model <ロード済みID>` を指定 |
| `LMStudio に接続できません` | LMStudio のサーバーが起動しているか確認（既定ポート 1234） |
| Git Bash/MinTTY で `NoConsoleScreenBufferError` | cmd/PowerShell/Windows Terminal で実行、または `winpty python tui_app.py` |
| サジェストが出ない／精度が低い | 語彙サイズを数百語に抑えるか、より大きいモデル（`--model qwen/qwen3.6-27b` 等）に切替 |
| 文字化けする | 本アプリは stdout を UTF-8 強制しています。ターミナルも UTF-8 表示対応のものをお使いください |

## 📂 ファイル構成

```
WordReCorrectWithAI/
├── words.txt          # ヘアサロン検索語彙 5970語（マスタ）
├── extract_words.py   # words.txt の先頭N語を tmp.txt へ書き出す
├── tmp.txt            # テスト用語彙（extract_words.py でサイズ調整）
├── ai_checker.py      # AI 判定ロジック（プロンプト構築・出力解析・類似度ガード）

└── README.md          # このファイル
```

## 📝 制限事項・チューニング

- **モデル精度**: Gemma2 2b は軽量ゆえ、読み違い系のタイポ（例: `しよーと`→`ショート`）を見逃すことがあります。これはモデルの能力限界です。コードは同一个で `--model` により大きいモデルへ切り替え可能です。
- **誤提案ゼロを優先**: 類似度ガードの設計上、漢字変換系タイポ（`びようしつ`→`美容室`）は文字レベルで遠いため見逃される場合があります。再現率を上げたい場合は `ai_checker.py` の `SIMILARITY_THRESHOLD` を下げてください（ただし偽陽性が増えます）。
- **コンテキスト上限**: 語彙を大きくしすぎると Gemma2 2b のコンテキスト（約8k）を超えます。`--check` の目安を参考に調整してください。
